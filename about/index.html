What is inside

Ten labs, one quiet workspace.

Each app is small on purpose. Pick one, play with it, and follow the explanation when you want the maths behind it.

Practise

Check what you know, then fill the gaps.

  • Practice Quiz — eight subjects, ten levels each, plus an A-Level maths extension.
  • Exam — take the test your teacher prepared. Answers go straight to the teacher.

Play

Small games with a real idea underneath.

  • Guide the Robot — program a route through a maze.
  • Tower of Hanoi — move the discs and see recursion at work.
  • Binary Search — guess the number and watch the search space shrink.
  • Knight's Tour — visit every square once with a knight.
  • Graph Colouring — colour the map so neighbours differ.
  • Guess the Password — crack a digit code with bulls and cows.

Understand

Follow the trail from the result to the reason.

  • Enigmatica Cipher Lab — encrypt, decrypt and break Caesar and Vigenère.
  • Huffman Coding — build a real frequency tree and measure the saving.
  • Fun Facts — a bank of stories from maths, computing and logic.

Teach

Set the work, then see how it went.

  • Exam builder — choose questions, set a time and publish a test.
  • Results — see who submitted and how they scored.
  • Teacher password — the server asks for it when it starts, so students cannot open the builder.

How it works

Simple on purpose.

Every lab is a static page: plain HTML, CSS and JavaScript. There is no account, no tracking and no build step. The quiz and games run in your browser.

The only part that needs a server is the exam. A small Python server saves each student's answers to a file on the teacher's computer. That is why the exam asks for a connection.

If you only want the labs, open index.html. For exams, run start.sh on Linux/macOS or start.bat on Windows.

Limits, honestly

This is a learning tool, not an exam board.

  • It is made for learning and practice. Do not use it for official assessment.
  • The quiz bank was checked by AI. Mistakes can still slip through; ask your teacher if an answer looks wrong.
  • The games are simplified models. They show the idea, not production code.
  • The exam is not a secure online exam platform. It needs the server, and the teacher password protects the builder, not the whole network.
  • Best scores live in this browser. Clearing site data removes them.
  • This is a small project. If something breaks, tell me.
