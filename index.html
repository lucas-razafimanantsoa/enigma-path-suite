The exam needs the EnigmaPath server

The exam saves each student's result to a file, which a web page cannot do on its own. Close this page, then double-click start.bat (Windows) or start.sh (Linux/macOS) in the EnigmaPath folder. Python 3 must be installed. Your browser opens by itself.
